Command Center: demo

My personal work dashboard: one place to start the day, with a game layer that rewards real work.

How this demo works: the real app reads my task board, calendar and team channels through n8n, asks an AI model (Gemini) to write a morning briefing from the facts, and turns finished work into XP for a 3D character. It runs on Cloudflare Workers behind a login. Everything below is fictional sample data; the 3D character at the bottom is the real one.
