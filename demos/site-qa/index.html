Site QA: demo report

An automated website quality check my team runs before sites go live. Below is its real output.

How this demo works: the check opens every page in a real browser (Playwright) and looks for accessibility problems (axe-core, WCAG 2.1 AA), broken links, unclear link text, oversized images, missing headings and layouts that wrap badly on desktop, tablet and phone. A teammate wrote the original script; I turned it into the team's shared, version-controlled tool and planned the QA platform around it. Here it ran on four of my own sites. No client data is used.
Built with Node.js, Playwright and axe-core. Source code is private (company project). · Seamor Estrabon
