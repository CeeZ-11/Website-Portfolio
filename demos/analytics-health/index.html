Analytics Health: demo

A tracking monitor I built at work: are Google Analytics and Tag Manager still working on every site?

How this demo works: an automation checks each website every day: is the tracking code on the page, is Google Analytics receiving data, and did key events like form submissions suddenly drop? This dashboard shows the results. All 25 sites here are fictional sample data (.example domains). Click a row to see a site's details.
